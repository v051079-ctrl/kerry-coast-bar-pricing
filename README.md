# Kerry Coast Hotel — Bar Pricing System

Streamlit application for managing spirits supplier prices, comparing costs per measure, tracking FOC deals (Buy X Get Y Free), and auditing supplier invoices.

## Features
- Master Catalog (PLU-based)
- Supplier Prices with deal support
- Automatic Price Comparison
- Invoice Check / discrepancy report
- Add / edit products and prices

## How to run locally
```bash
pip install -r requirements.txt
streamlit run app.py
